# 树状浏览器（静态）

把图谱按 **教材 → 章 → 节 → 概念** 逐层展开，点节点看详情。无框架、无构建、无后端。

## 跑起来

```bash
# 1. 生成数据（依赖 dist/，先 kg:build）
pnpm kg:build && pnpm kg:demo

# 2. 起静态服务（必须走 HTTP，file:// 会被 CORS 拦）
python3 -m http.server 8765
# 或 npx serve .

# 3. 打开
open http://localhost:8765/demo/index.html
```

> **从仓库根起服务**（`knowledge/`），因为「查看教材原文」链接指向 `content/…` 的相对路径。
> 也可以只服务 `demo/`，但原文链接会失效（不影响其它功能）。

## 数据怎么来

全部由 `tools/kg/src/build_demo.ts` 从 `graph/` 生成到 `demo/data/`，与 `dist/` 同源：

| 文件 | 体积 | 何时加载 |
|---|---:|---|
| `tree.json` | 341KB | 首屏（教材/章/节，3,797 节点） |
| `catalog.json` | 10KB | 首屏（学科 → 教材） |
| `detail.json` | 1.3MB | 首次点节点 |
| `search.json` | 665KB | 首次搜索（概念名索引） |
| `concepts/<学科>.json` | 单科 ≤800KB | 点开该学科第一个概念 |
| `adj.json` | 2.2MB | 点「看关系网」 |

`demo/data/` 是**派生产物**，已 gitignore——不手改，改数据请改 `graph/` 后重跑 `pnpm kg:demo`。

## 左侧树：默认按年级

一级是「一年级 … 九年级」，二级是学科，三级是册次——与 `content/年级/学期/学科/` 的目录结构、
以及教师「我教八年级 → 教数学」的思考顺序一致。右上角可一键切回「按学科」。

按学科分组时，语文/数学/道法各 18 册平铺，找某一册要靠标题辨认年级；
按年级分组后，一年级 8 册、八年级 16 册，一屏能看全该年级开了哪些课。

## 首屏：学科 × 年级 热力矩阵

打开页面先看到 10 学科 × 9 年级的格子，每格是该年级的概念数（颜色深浅按 `(n/max)^0.55` 压缩，
否则 553 的大格会把其它格压成白色）。点格子跳到对应教材。

一眼能看出的结构性问题：**化学只有 9 年级 354 个概念**、**物理从 8 年级才开始**、
**数学在 9 年级最密（153）**、**语文/道法 1–9 年级铺满**。

## 关系网视图

概念卡上点「**看关系网 →**」，进入 Canvas 力导向图：

- **两级邻居**（默认 2 跳，可切 1 跳），上限 160 节点，超出会显示「已截断」
- 三类边分色：先修（橙）/ 上位（绿）/ 相关（灰，半透明）；可单独勾选
- 拖拽节点、滚轮缩放、点节点跳到该概念
- 用 **Canvas 2D 自写力导向**，不引 three.js——原因写在 `net.js` 顶部注释：
  数据是稀疏图（度数中位 3、二跳中位 44），3D 只增加遮挡；且 three.js 会带进 ~600KB 依赖

规模参考：`光合作用` 二跳 132 节点 / 140 边；度数最大的枢纽（244 度）截断到 160 节点，仿真 300 次迭代约 20ms。

布局质量（`_screen()` 导出坐标量化，900×600 视口）：

| 概念 | 节点 | 缩放 | 包围盒覆盖 | 最近点距 | 重叠对 | 越界 |
|---|---:|---:|---:|---:|---:|---:|
| 测量长度的方法 | 39 | 46% | 55% | 42.5px | 0 | 0 |
| 一次函数 | 102 | 44% | 50% | 11.1px | 1 | 0 |
| 光合作用 | 132 | 35% | 23% | 9.4px | 5 | 0 |

两条关键约束（都是踩坑后加的）：
- **理想边长 k 夹在 46–120**：纯 `√(面积/n)` 在节点少时给出 150+，包络撑开后 fit 只能缩到 0.4
- **节点半径按屏幕像素固定**（世界半径 = 屏幕值 / scale）：否则缩小后节点只剩 3px，看着像空的

用的是 Fruchterman–Reingold（`k=√(面积/n)`、斥力 `k²/d`、引力 `d²/k`、温度退火）。
早先用「斥力 ÷ 节点数 + 固定弹簧」，39 个节点就全挤成一团——参数随规模失效。

## 已知边界

- 搜索是**子串匹配**，不做分词与同义词（「光合」能命中「光合作用」，但「carbon fixation」不行）
- 概念的 `standards` / `gradeRange` 来自 `dist`（build 派生字段），跳过 `kg:build` 会是空的
- 没有做题、没有诊断——本仓库没有题库，这里只做**结构化浏览**
- 关系网是**局部子图**，不是全库网络：8,282 个概念的全量力导向会是一团毛球（37% 概念度数 ≤2）
