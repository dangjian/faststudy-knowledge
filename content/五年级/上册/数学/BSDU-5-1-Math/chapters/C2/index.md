## 探索三角形内角和

（配图：大小两个三角形的对话）我是一个大三角形，三个内角的和一定比你的大。我虽然小，但是三个内角的和不一定小。

小组活动：每人从附页 1 中选一个三角形，量一量，填一填。

|  |  |  |  |

- 不用量，我知道三个内角的和是 180°。
- 真的吗？让我量量看……
- 测量要认真，要实事求是。

小组交流发现了什么？

（配图：第 1 组、第 2 组小组活动记录表（各组量的三角形有锐角三角形、钝角三角形、直角三角形，内角和大多在 180° 附近））

- 我和奇思量的都是钝角三角形③，结果怎么差这么多……
- 我们组测量的三角形内角和在 178° 到 183° 之间……

实际上，三角形三个内角的和就是 180°，只是因为测量有误差……

你有什么办法验证三角形的内角和是 180° 吗？做一做，与同伴交流。

（配图：把三个内角撕下来拼成一个平角；把三个内角折在一起）

- 180° 是一个平角，把三个角撕下来拼在一起……
- 还可以把三个内角折在一起……

三角形内角和等于 180°。

## 了解尺规作图

古希腊数学家认为直线和圆是世界上最简单、最美丽的图形。他们定了一条有趣的规则：只能用"无刻度"直尺和圆规来画图，这就是尺规作图。

（配图："无刻度"直尺和圆规（标注手柄、固定针、笔尖））

直尺只能用来画直的线，不能量长度。

读一读，你知道了什么？有什么好奇的问题？

- 尺规作图只能用圆规和无刻度的直尺……
- 尺子我会用，圆规应该怎么用呢？
- 用无刻度直尺和圆规能画出什么图形？

看一看，照样子画一画，说一说。

（配图：用圆规画圆的步骤）

捏住圆规的手柄，把针尖固定在纸面上，针尖的位置一定要固定……笔尖在纸面上旋转，留下的痕迹是一段弧。把弧继续画下去就能画出一个圆。

你能用尺规画一个图案吗？想一想，试一试。

（配图：用尺规画的图案）我想画一个小朋友，先用圆规画头，再用无刻度直尺……

### 试一试

请你借助尺规画一条线段，使它和下面的线段 AB 长度相等。说一说你准备怎样做。

- 先用尺子量出线段 AB 的长度……
- 不行，要用无刻度直尺和圆规。
- 我可以用圆规把这条线段的长度"移"过去。

用尺规画一画，和同伴交流你的方法。

首先，用无刻度直尺画一条直线，在上面取点 C。其次，针尖扎在点 A，笔尖调到点 B，量出 AB 的长度。最后，针尖扎在点 C，用圆规在直线上截取 AB 的长度……

尺规作图要保留作图的痕迹。

我国古代的甲骨文中有"规"和"矩"二字，"规"指圆规，"矩"指直角形拐尺。我国古代的工匠巧妙地使用规和矩，可以画出点、线、圆、弧、方形、三角形等各种图形。

古希腊数学家在考虑几何学问题时，约定作图时只能有限次使用无刻度直尺和圆规，并提出了三大作图问题。你知道是什么问题吗？

## 探索三角形三边关系

（配图：中国"神舟"飞船首飞成功纪念邮票（等边三角形））我也有这两枚邮票，太漂亮了！我量过，它们的三条边都相等。

请你用尺规作出上面这个等边三角形。

先作和边长相等的线段，就得到了三角形的一条边和两个顶点。找第三个顶点只能利用圆规了……

你能用圆规找到第三个顶点吗？作一作，说一说。

（配图：两条弧相交确定第三个顶点）

- 顶点在这条弧上。
- 顶点也在这条弧上。
- 我发现顶点就是两条弧的交点。

根据给定的线段 a，b，用尺规作等腰三角形。

- 以线段 a 为底，b 为腰……
- 以线段 b 为底，a 为腰，作不出三角形。

看来，不是有三条线段就能作出三角形。

### 试一试

怎样长度的三条线段可以作出三角形？妙想是这样做的，你看懂了吗？试一试。

（配图：用圆规和线段 a，b 与不同长度的线段 c 试作三角形）

- 线段 c 太短了，画不成。
- 线段 c 太长了，也画不成。
- 画成了！我发现线段 c 不能太长，也不能太短，真奇妙！

想一想，能围成三角形的三条线段的长度之间有什么关系？

- 我知道两点之间线段最短，所以……
- 画几个三角形，量一量，算一算。
- 我用不同长度的小棒试一试。

三角形任意两边之和大于第三边。

## 探索内角和的奥秘

生活中有各种各样的四边形，它们的内角和分别是多少度呢？

**阅读理解**

- 我们探索了三角形内角和，四边形内角和……
- 这些四边形形状不同，内角和是否一样呢？

**制订计划**

- 先准备一些四边形，像研究三角形内角和一样，量出每一个内角的度数……
- 或者把四个内角撕下来，拼在一起……
- 可以从长方形、正方形这些特殊的四边形开始……
- 三角形内角和是 180°，可以把四边形变成三角形……

### 解决问题

（配图：测量四边形内角、拼角活动）

- 我来测量一下四个内角。长方形四个内角都是 90°，内角和是 360°。
- 我把四边形分成了两个三角形。
- 我把四个内角撕下来，拼成了一个周角……

### 回顾反思

- 根据三角形内角和是 180°，可以把要研究的图形转化为三角形。
- 研究三角形内角和的方法给了我启发。

五边形、六边形……它们的内角和分别是多少度呢？
