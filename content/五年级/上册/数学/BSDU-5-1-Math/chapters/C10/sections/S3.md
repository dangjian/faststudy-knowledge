## 摸球游戏

（配图：不透明的盒子里装着红球和黄球）红球多还是黄球多？

不打开盒子看，如何知道盒子里红球多还是黄球多？

- 可以通过摸球来判断盒子里红球多还是黄球多。
- 摸球后记下颜色，要再放回到盒子里，并使劲摇一摇。
- 需要摸多少次，才能判断出盒子里哪种球多呢？
- 5 次可以吗？5 次太少了，多摸几次吧。我们先摸 20 次。

小组合作进行摸球活动，在下表中记录每次摸到的球的颜色，并整理数据。

|--------|---|---|---|---|---|---|---|---|---|----|----|----|----|----|----|----|----|----|----|----|
| 颜色 |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |

推测：摸出红球的次数（　）；摸出黄球的次数（　）；（　）球多。

交流各小组的结果，有什么困惑和发现？

- 我们小组摸到红球的次数和其他组不一样，怎么回事呢？
- 每次摸到的球是不确定的，可能是红球，也可能是黄球。
- 大多数小组都是摸到红球的次数多……

根据大家的数据，推测一下盒子里哪种颜色的球多。

大多数小组都是摸到红球的次数多，我推测盒子里红球多。
