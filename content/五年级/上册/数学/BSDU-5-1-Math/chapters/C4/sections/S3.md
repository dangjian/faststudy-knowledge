## 包装

（配图：包装礼品盒。包装纸 2.4 元/m，彩带 0.85 元/m。包装一个礼品盒要用 1.2 m 长的包装纸，还要用 0.4 m 长的彩带。）

买包装纸需要多少元？想一想，算一算。

2.4×1.2=（　）

- 2.4 乘 10，1.2 乘 10……
- 24 个 0.1 乘 12 个 0.1 是 288 个 0.01……

2.4×1.2=2.88（元）

（配图：竖式（24×12=288））

答：买包装纸需要 2.88 元。

买彩带需要多少元？与同伴交流。

0.85×0.4=（　）

- 85 个 0.01 与 4 个 0.1 相乘，是 340 个 0.001……340 要除以……
- 85×4=340

0.85×0.4=0.340=0.34（元）

小数末尾的 0 可以去掉。

（配图：竖式（85×4=340））

答：买彩带需要 0.34 元。

积的小数位数与乘数的小数位数有什么关系？算一算，想一想。

| 算式 | 第一个乘数的小数位数 | 第二个乘数的小数位数 | 积的小数位数 |
|------|----------------------|----------------------|--------------|
| 2×0.3=0.6 |  |  |  |
| 0.2×0.3= |  |  |  |
| 0.13×2= |  |  |  |
| 0.13×0.2= |  |  |  |

- 在 0.2×0.3 中，0.2 是 2 个 0.1，是一位小数，0.3 是……结果是 6 个 0.01，是两位小数。
- 我发现积的小数位数是两个乘数的小数位数之和。
