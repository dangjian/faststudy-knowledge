# 第二单元 我们自己

在生活中，眼睛、耳朵、鼻子、舌头、皮肤可以帮助我们感觉周围的事物。它们就是感觉器官。

## 1 我们的身体

（配图：我们在锻炼身体）

### 聚焦

我们的身体包括哪些部分？

### 探索

做一做，认识我们的身体。

（配图：让光透过手指——被遮住的一半和露出的一半是一样的）（配图：摸骨头）（配图：我听到咕噜的声音、我听到呼吸的声音）

观察我们的身体，用画图的方式记录下来。

（配图：身体结构示意图——头、颈、躯干、四肢）

记录单：我的身体，日期：____。

### 研讨

- 我们的身体从上到下有哪几部分？
- 与小猫、小狗相比，我们的身体有什么不同？

### 拓展

想知道我们身体内部是什么样的吗？阅读科普书是一种很好的方法。

## 5 通过感官来发现

（配图：眼睛看、耳朵听、手摸、鼻闻、舌尝）

安全提醒：不要闻或尝陌生的物品。

### 聚焦

我们用眼睛、耳朵、鼻子、舌头和皮肤等感觉器官进行观察。当我们观察时，各种感官分别能告诉我们什么信息？

### 探索

到校园中，用多种感觉器官观察花园或者绿地。

整理我们的观察记录，并画下来。

| 校园观察记录 |  |
|------|------|
| 看到的 |  |
| 听到的 |  |
| 闻到的 |  |

日期：____　把看到的、听到的或闻到的选择两种画下来。

### 研讨

- 我们观察到了哪些信息？
- 反复观察会得到更多信息吗？

### 拓展

感觉器官很容易受到伤害，我们要注意保护它们。

- 用眼：不要看强光，不随意揉眼睛，多做户外运动。
- 用鼻：不用力擤鼻涕，不随意抠鼻孔，保持鼻腔清洁。
- 用耳：保持耳道干燥，不随意掏耳朵，不长时间戴耳机。

## 科学阅读

### 皮肤很重要

皮肤是人体最大的器官，成年人的皮肤面积大概有一扇教室门那么大。

皮肤可以从外界接收到冷、热、痒、痛、压等大量信息，并向大脑报告，让身体作出反应。

（配图：抚触婴儿脚底）（配图：刺尖触碰手指）（配图：抱着足球的男孩）

皮肤又是一个很好的保护罩，能阻挡水、尘土、病菌和有害光线等进入身体。

皮肤还是人体的"空调器"，可以凭借出汗等来调节体温。

### 残障人士的助手

盲文和盲道是专门为视力有障碍的人设计的。盲文是靠触觉感知的文字，方便视障人士摸读。（配图：电梯按钮上的盲文）

盲道则可以帮助视障人士在公共场所安全行走。（配图：盲道）

助听器是一种辅助听障人士提高听力的小型扩音器，为听障人士带来很大便利。（配图：助听器）
