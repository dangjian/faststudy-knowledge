# 第8章 近代经济、社会生活与教育文化事业的发展

根据土地改革总路线和《中国土地法大纲》规定，各个解放区先后开展土地改革运动。在中国共产党领导下，经过艰苦工作和斗争，解放区土地改革历时一年多顺利完成，广大农民分得土地、农具、耕畜、房屋等。

（配图：宣传《中国土地法大纲》）
（配图：翻身农民在分得的土地上插界标）

解放区土地改革，使农村阶级关系和土地占有状况发生根本性变化，激发了农民革命和生产的积极性。翻身农民踊跃参军参战，为人民解放战争的胜利提供了重要的人力、物力保障。

**想一想**
解放区土地改革对人民解放战争的胜利起到了什么作用？

**相关史事**
抗战胜利后，国民党政府依靠美国发动内战，美国商品大量涌入中国市场，排挤国货。国民党官僚资本迅速膨胀，垄断经济，挤压民族资本主义企业。国民党政府还不断增加苛捐杂税、滥发纸币，导致恶性通货膨胀，民族资本主义陷入绝境，国统区人民在饥饿中挣扎。

## 三大战役和南京解放

经过一年的战争，国民党军队主力深陷陕北和山东解放区。中共中央抓住机遇，决定挺进中原，以主力打到外线去，将战争引向国统区。1947年夏，刘伯承、邓小平率领晋冀鲁豫野战军主力，在山东西南强渡黄河天险，千里跃进大别山，直接威胁南京、武汉，揭开人民解放军战略进攻的序幕。随后，其他战场的人民解放军也相继转入进攻。经过连续作战，人民解放军先后歼灭国民党军精锐200多万人，迫使国民党军队主力退守沈阳、北平、徐州等孤城，被动防御作战。

（配图：人民解放军战略进攻形势图）

**学史崇德**
1948年5月，在解放河北隆化战斗中，共产党员董存瑞(1929—1948)率全班连续炸掉4座炮楼、5座碉堡。部队发起冲锋时，突然遭到一座桥型暗堡中机枪火力的封锁，突击受阻。董存瑞冲到桥下，却发现这座暗堡无处放置炸药，但总攻时间已到，他毅然托起炸药包，抵住桥身炸毁暗堡，壮烈牺牲，以自己年轻的生命为部队开辟了前进道路。1950年9月，董存瑞被授予“全国战斗英雄”称号。

（配图：董存瑞塑像）

毛泽东和中共中央认为战略决战的时机已经成熟，及时抓住决战时机，正确选定决战方向，针对各战场不同情况制定作战方针，先后发起辽沈、淮海、平津三大战役。

1948年9月，辽沈战役打响。林彪、罗荣桓指挥东北野战军首先攻占辽宁锦州，一举切断敌人向关内的退路。随后，攻占长春、沈阳，解放东北全境。

11月，辽沈战役刚结束，华东野战军与中原野战军在刘伯承、陈毅、邓小平、粟裕、谭震林等指挥下，在以徐州为中心的广大地区发起淮海战役，歼灭大量敌军。1949年1月，淮海战役胜利结束，长江中下游以北广大地区获得解放。

（配图：三大战役示意图）

**读地图**
找出三大战役的主要战场。

几乎与淮海战役同时，东北野战军挥师入关，与聂荣臻指挥的华北军区部队发起平津战役。解放军先后攻占张家口、天津，包围北平。北平国民党守军总司令傅作义在中国共产党争取下，接受和平改编。1949年初，北平和平解放。平津战役的胜利，使华北全境基本解放。

（配图：人民解放军解放北平后举行盛大入城式）

三大战役共歼灭和改编国民党军队150多万人，国民党军队主力基本被消灭，大大加速了人民解放战争在全国的胜利。

1949年4月，人民解放军百万雄师兵分三路，横渡长江，解放南京，宣告国民党反动统治覆灭。国民党残余势力退往台湾。

### 中共七届二中全会和新民主主义革命胜利的意义

1949年3月，中共中央在河北西柏坡召开七届二中全会。会议确定了全国胜利后党在政治、经济、外交方面的基本政策，决定党的工作重心由乡村转向城市，党的奋斗目标是把中国逐渐由落后的农业国转变为先进的工业国。

在会议上，毛泽东告诫全党，夺取全国胜利只是万里长征走完第一步，中国革命以后的路更长，工作更伟大，更艰苦。他强调，全党同志务必继续保持谦虚、谨慎、不骄、不躁的作风，务必继续保持艰苦奋斗的作风。

（配图：中共七届二中全会会场）

**相关史事** 七届二中全会结束后，中共中央离开西柏坡向北平进发。临行前，毛泽东对周恩来说，今天是进京的日子，进京“赶考”去。周恩来说，我们应当都能考试及格，不要退回来。毛泽东说，退回来就失败了。我们决不当李自成，我们都希望考个好成绩。1949年3月底，毛泽东等中央领导人与中央机关、人民解放军总部进驻北平香山，标志着中国革命重心从农村转向城市。

新民主主义革命的胜利，是毛泽东思想的伟大胜利，它结束了中国半殖民地半封建社会的地位和外患频仍、长期战乱、四分五裂的局面，实现了中华民族的独立和人民的解放，从根本上改变了中国社会的发展方向，为实现中华民族伟大复兴创造了根本社会条件，深刻影响了世界历史发展进程。

**歌曲《没有共产党就没有新中国》的来历**

1943年3月，国民党出版署名蒋介石的《中国之命运》一书，鼓吹没有国民党就没有中国。8月，《解放日报》发表《没有共产党，就没有中国》的社论，予以反击。受此启发，人民音乐家曹火星创作歌曲《没有共产党就没有中国》。这首歌随着抗日战争和解放战争节节胜利而唱响全中国，迎来新中国的诞生。1950年，毛泽东建议在歌曲名称上添加“新”字。这就是歌曲《没有共产党就没有新中国》的来历。

### 第22课 活动课 探寻红色文化的历史基因

《启航——中共一大会议》

1921年，浙江嘉兴南湖的一条游船见证了中国历史上“开天辟地的大事変”——中国共产党的诞生。这条游船因而获得了一个永载中国革命史册的名字——红船。红色是中国共产党和中华人民共和国最鲜亮的底色。你知道红色文化是在怎样的历史环境中孕育的吗?为什么能够影响一代又一代的中国人呢?今天，就让我们一起探寻红色文化的历史基因吧。

**活动目标**

1. 通过查阅资料、调研访谈、实地考察、研学旅行、专题研讨、归纳概括、比较分析等多种方式，培养多渠道获取和处理有关红色文化历史信息的能力，提高书面和口头语言表达的能力，培育时空观念、史料实证、历史解释等核心素养。
2. 通过对新民主主义革命时期的革命史事、英雄人物、革命精神等内容的学习，知道红色文化的形成过程和基本内容，认识红色文化是党和人民共同创造的、极具中国特色的先进文化；明确新时代青年学生的责任担当，传承红色基因，涵养家国情怀。

**活动任务**

1. 通过历史和语文、道德与法治、地理、艺术等课程的学习，整理各课程中有关中国共产党在新民主主义革命时期的重要人物、事件、旧址及作品等，梳理出这一时期中国共产党人的精神谱系，完成跨学科主题学习知识图谱。
2. 通过鉴赏革命影视剧、演唱革命歌曲、朗诵革命诗歌、编排革命历史剧、举办革命故事会等多种活动方式，感受并理解红色文化。

**活动过程**

1. **提出问题** 新民主主义革命时期，有哪些以“红”命名的人、事、物?有哪些精神可纳入中国共产党人的精神谱系?如何认识革命精神，弘扬革命传统，传承红色基因?
2. **合作探究** 全班根据实际情况，分成若干小组，确定主题，制订计划，明确分工。比如，一些小组收集整理语文、道德与法治、地理等课程中相关知识。另一些小组可与文旅部门联系，了解当地红色文化资源，实地参观博物馆、纪念馆、遗址等，有条件的地方还可走访相关人物，并作好记录。
3. **形成成果** 各组在研究资料的基础上，完成“探寻红色文化的历史基因”跨学科主题学习知识图谱，撰写访谈记录、心得体会、研究报告等文本资料，整理好相关图片、音视频及相关课件等。
4. **成果展示** 举办主题班会，各组代表汇报并展示研究成果，各组间积极研讨交流，取长补短，最后形成全班的成果汇报材料。成果宣传展示的形式可以是黑板报、手抄报，也可借助新媒体技术，制作成喜闻乐见的网页、视频等，还可举行学校社团活动，举办年级或学校成果展示会等。

**学史方法（一）如何评价历史人物**

第6课《戊戌变法》的内容中，有中国近代史上著名的历史人物梁启超。历史人物是历史活动的主体，评价历史人物有助于把握历史活动的进程和影响。评价历史人物，应从五个方面入手。

1. 确定历史人物的时代背景，弄清历史人物的生卒年和国别。如梁启超生于1873年，经历了晚清和民国初年，1929年去世，国别为中国。
2. 分阶段梳理历史人物参与的历史事件，了解这一历史人物在其中发挥的作用。如戊戌变法前，梁启超通过撰写文章、创办报刊、学堂讲课等方式，宣传维新思想；变法失败后，在海外推动君主立宪；民国成立后，反对袁世凯称帝。
3. 从政治、经济、文化等方面，了解历史人物的活动。如梁启超在政治方面的作为、在思想文化方面的贡献等。
4. 了解历史人物的阶级属性，揭示其活动所代表的阶级利益。如梁启超代表的中国民族资产阶级，有哪些历史进步性和历史局限性。
5. 评价历史人物，主要看其对解决社会主要矛盾和影响历史发展趋向所起的作用，是否顺应了历史发展潮流，是推动还是阻碍了生产力发展及人类社会进步。顺应历史潮流、推动历史进步的历史人物，就要充分肯定；反之就要予以否定。

**学史方法（二）如何从历史图像中获取信息**

第21课《人民解放战争的胜利》有一幅宣传《中国土地法大纲》的历史图像。历史图像包含着丰富的历史信息，掌握其中的历史信息有助于更好地理解历史。如何从历史图像中获取信息，可从五个角度考虑。

1. 阅读图像的标题，了解图像的主题——宣传《中国土地法大纲》。
2. 依方位（从上到下或从左到右）、按系统（如从人物到背景）、有条理地观察图像，重点观察图像的主要部位（常会用位置、色彩等体现），如图像中间的文件——《中国土地法大纲》就是图像的焦点。
3. 看图像的表象信息细节，观察图像中人物的穿着打扮、身体语言、神情气质，以判断其身份、情绪和活动背景等。
4. 在观察图像的表象信息基础上，思考图中的形象代表着历史上哪些人物，反映了哪个时期的历史场景，揭示图像反映的时代风貌、重要社会现象和生活状况，在头脑中形成合理的历史景象。
5. 逐层深入地解释图像，先直接描述画面场景，说说画面带给自己的感受；然后解释图像中不同人物或图案所处的位置、呈现的大小比例、图案的象征意义等历史信息；最后解释图中人物的身份、图中历史事件或场景等出现的背景等，并结合所学知识加以评价。

> ①中国古代和近代的人物像多有不同，中国古代人物像多为后人所绘制，中国近代人物像多为照片。

**学史方法（三）如何从重大历史题材影视剧中获取信息**

第1课《鸦片战争》课后活动中，建议观看电影《鸦片战争》；第12课《中国共产党诞生》课后活动中，建议观看电影《建党伟业》。观看重大历史题材影视剧，是学习历史的辅助手段，能够获取并印证历史知识。如何从重大历史题材影视剧中提取历史信息？

1. 了解重大历史题材影视剧是本着“大事不虚，小事不拘”的原则创作的，剧中主要人物及主要事件要有历史依据，不能虚构。所以，重大历史题材影视剧，它的主要角色和情节是反映历史真实的。但是，任何影视剧都是文学创作，它不等同于历史著作。
2. 重大历史题材影视剧，剧情细节、次要人物、对话场景是可以虚构的，不一定具有历史实证，但必须符合历史逻辑和生活逻辑。所以，从影视剧中获取历史信息时，要了解它所反映的历史时期、历史事件、历史人物、历史现象的重要程度等。
3. 观察重大历史题材影视剧中的场景、服饰、台词、动作等，感受时代氛围和历史风貌。
