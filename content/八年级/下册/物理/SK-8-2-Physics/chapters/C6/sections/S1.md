# 常用物理量及其单位

《义务教育物理课程标准》规定的常用物理量及其单位如下。表中「物理量」一列给出量的名称与符号，「单位」一列给出对应的单位名称与符号，备注栏列出常用单位之间的换算关系；后半部分为国际单位制词头，用于构成十进倍数和分数单位。

| 物 理 量 |  | 单 位 |  | 备 注 |
|---|---|---|---|---|
| 名 称 | 符 号 | 名 称 | 符 号 |  |
| 质量 | m | 千克 克 毫克 | kg g mg | 1 g = 10⁻³ kg 1 mg = 10⁻⁶ kg |
| 密度 | ρ | 千克/ 米3 克/ 厘米3 | kg / m3 g / cm3 | 1 g / cm3 = 10³ kg / m3 |
| 能量 | E | 焦耳 | J |  |
| 力 | F | 牛顿 | N |  |
| 压强 | p | 帕斯卡 | Pa |  |
| 时间 | t | 秒 分 时 | s min h | 1 min = 60 s 1 h = 3 600 s |
| 速度 | v | 米 / 秒 千米 / 时 | m / s km / h | 1 m / s = 3.6 km / h |
