# 整理与复习

## 我学到了什么

我把圆柱和圆锥比较了一下，它们都可以由一个平面图形得到：

（配图：长方形旋转得到圆柱、直角三角形旋转得到圆锥）

我画图整理一下知识。

本单元学习的立体图形：

- 圆柱：认识各部分名称（侧面、底面、高）；表面积——侧面积 S=Ch，底面积 S=πr²；体积 V=Sh。
- 圆锥：认识各部分名称（侧面、底面、高）；体积 V=(1/3)Sh。

它们的侧面展开图如下：

（配图：圆柱的侧面展开图——侧面沿高剪开展开成长方形（长=底面周长，宽=高）；圆锥的侧面展开图——扇形）

S底=πr²　　S侧=2πrh　　S表=2πrh+2πr²

圆柱的体积=底面积×高，V=Sh；圆锥的体积=(1/3)×底面积×高，V=(1/3)Sh。

我列个表整理一下。

|  | 正比例 | 反比例 |
|------|--------|--------|
| 相同点 | 都是一个量变化，另一个量随着变化 | 都是一个量变化，另一个量随着变化 |
| 不同点 | 比值一定 | 积一定 |
|  | 在一条直线上 | 不在一条直线上 |
| 例子 | 圆的周长与圆的直径 | 路程一定时，速度与时间 |

|  |  |
|------|------|
| 比例 | 两个比相等。如 12:3=20:5。可以按比将图形放大或缩小。 |
| 比例尺 | 图上距离:实际距离=比例尺　　图上距离/实际距离=比例尺 |

（配图：比例尺为 1:1000 的曲线示意图（A、B 两点））
