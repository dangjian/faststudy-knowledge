## 神奇的 0

（配图：三组找规律算式卡片）

- 3×3=9，2×3=6，1×3=3，0×3=？
- 8×30=240，8×20=160，8×10=80，8×0=？
- 200×3=600，200×2=400，200×1=200，200×0=？

我来啦……

算一算，填一填，说一说你是怎么想的。

0×3=　　8×0=　　200×0=　　0×□=

- 3 个 0 相加得 0，所以 0×3=0。
- 0 乘任何数都得 0。

下面是一组与 0 有关的算式，请你用竖式算一算。

0 乘 2 得 0……
