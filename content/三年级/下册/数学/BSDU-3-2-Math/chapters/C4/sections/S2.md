## 动物体重我说明

蜂鸟和青蛙是小型动物，猕猴和藏羚羊是中型动物，通常用"克"或"千克"来表示它们有多重。

1 克、1 千克分别有多重？掂一掂，称一称。

（配图：3 枚曲别针约重 1 克，记作 1 g；4 个苹果约重 1 千克，记作 1 kg）

1 千克=1000 克

蜂鸟的体重是 2 克，怎样说明它的体重呢？青蛙、猕猴、藏羚羊呢？

议一议，选择哪些物品可以说明蜂鸟、青蛙、猕猴、藏羚羊的体重？

制作它们的体重"说明书"，并与同伴交流。

（配图：动物体重"说明书"记录表）

| 动物体重 | 生活中的物品 | 估计数量 | 实际数量 |
|----------|--------------|----------|----------|
| 蜂鸟大约重 2 克 |  |  |  |
| 青蛙大约重 150 克 |  |  |  |
| 猕猴大约重 6 千克 |  |  |  |
| 藏羚羊大约重 50 千克 |  |  |  |

称一称。

画一画。

写一写。

蜂鸟的体重大约 2 克，它很轻，和 10 颗瓜子一样重。
