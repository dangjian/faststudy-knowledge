### 字词句运用

读一读，注意加点的字，看谁读得准。

（我会根据词语的意思来判断多音字的读音。）

| 多音字 | 词语举例 |
|--------|----------|
| 号 | 口号 hào　　号叫 háo |
| 当 | 每当 dāng　　当作 dàng |
| 种 | 种子 zhǒng |
| 好 | 好人 hǎo　　好客 hào |
| 分 | 分别 fēn　　水分 fèn |
| 都 | 全都 dōu　　首都 dū |
| 教 | 教师 jiào　　教书 jiāo |
| 没 | 没有 méi　　沉没 mò |
| 行 | 银行 háng　　飞行 xíng |
| 干 | 干活 gàn |

读一读，猜一猜词语的意思。

不言不语　　只言片语　　三言两语　　千言万语

少言寡语　　豪言壮语　　自言自语　　甜言蜜语

注意下面句子中加点的词语，仿照例子在括号中加上合适的词语，再读一读。

- **细长的**葫芦藤上长满了绿叶，还开出了**雪白的**小花。
- **茂密的**枝叶向四面展开，就像搭起了一个个**绿色的**凉棚。
- （　　）天空飘着（　　）气球。
- （　　）池塘开满（　　）荷花。

### 书写提示

有的字左边短，右边长；有的字左边长，右边短。

（例字：观、吗、如。）

### 日积月累

- 黑发不知勤学早，白首方悔读书迟。
- 一日读书一日功，一日不读十日空。
- 书山有路勤为径，学海无涯苦作舟。
