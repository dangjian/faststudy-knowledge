## 6 "小房子"展示会

（配图：我们的小房子展示会）

### 展示介绍

向同学介绍自己的小房子，说一说各部分用了什么材料。

（配图：窗户是用透明塑料薄膜做的，这样房间会比较明亮）

### 相互评价

造房子是有标准的，对照下面的标准，做到的请打"√"。

| 评价标准 | 自我评价 | 他人评价 |
|----------|----------|----------|
| 1. 用了两种以上的材料 |  |  |
| 2. 房子稳固，不容易变形 |  |  |
| 3. 有足够大的门、窗 |  |  |
| 4. 房间比较明亮 |  |  |
| 5. 节约材料 |  |  |

### 反思改进

- 与其他组相比，我们的房子所用的材料是否合理？
- 同学的哪些想法让我们受到启发？
- 在合作中，我为小组做了什么？

### 拓展

如果我们要养几盆植物，应该放在房间的什么位置比较合适？
