## 3 家里的物品

（配图：随着材料的改进，我们的家变得越来越丰富多彩）

### 聚焦

我们家里有很多物品，它们是用什么材料做的？

### 探索

观察家里的物品。金属可以造房子，也可以做勺子、杯子。

资料：常见材料类别有金属、塑料、玻璃、布、纸、木、陶瓷等。

为方便记录，可以先给物品编号，再按材料类别给家里的物品分类。

| 材料 | 金属 | 塑料 | 玻璃 | 布 | 纸 | 木 | 陶瓷 |
|------|------|------|------|----|----|----|------|
| 物品号码 |  |  |  |  |  |  |  |

日期：____　有些物品组合了几种材料。

### 研讨

- 我们的分类和其他同学的分类有什么不同？
- 哪些材料既可以用来造房子，也可以用来制造常用餐具？

### 拓展

收集身边的各种废旧材料，为建造我们的小房子作准备。
