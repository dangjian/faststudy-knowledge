## 文物中的乘法口诀

（配图：秦简和楚简文物）2002 年在湖南里耶出土的秦简和 2023 年在湖北荆州出土的楚简，都刻有九九乘法口诀表。

"二五而十，三五十五"，这两句口诀是什么意思？

你能回答淘气的问题吗？做一做，说一说。

- "二五而十"：2 个 5 相加是 10。
- "三五十五"：3 个 5 相加是 15。

圈一圈，数一数，尝试编出 5 的乘法口诀。

（配图：点子图，每行 5 个圆点，共 9 行）

| 算式 | 口诀 |
|------|------|
| 5×1=5 | 一五得五 |
| 5×2=10 | 二五一十 |
| 5×3=15 | 三五十五 |
| 5×4=（　） | 四五（　） |
| 5×5=（　） | 五五（　） |
| 5×6=（　） | 五六（　） |
| 5×7=（　） | 五七（　） |
| 5×8=（　） | 五八（　） |
| 5×9=（　） | 五九（　） |

"二五而十"就是"二五一十"。

想一想，怎样记住 5 的乘法口诀？

- 只要记住五六三十，再加 1 个 5，就是五七三十五了。
- 口诀的最后一个字不是五就是十。
