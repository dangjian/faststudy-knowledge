## 6 我们来钓鱼

### 实施方案

根据设计图，制作钓鱼玩具。

### 测试评价

用我们制作的钓鱼玩具来钓鱼。

| 钓鱼玩具评价表 |  |
|----------------|---|
| 项目要求 | 完成度 |
| 1. 用提供的材料设计并制作钓鱼玩具 |  |
| 2. 钓鱼线长度至少半米 |  |
| 3. 半分钟内至少钓起 5 条鱼 |  |
| 4. 与同学合作完成 |  |

### 反思改进

哪个组钓起的鱼比较多？讨论其中的原因。

"用了两块磁铁后，力量更大了！""把磁铁粘在鱼身上，钓鱼更方便！"

怎样改进我们的钓鱼玩具？先讨论，再设计、制作、测试。

- 如果鱼离我们更远，应该怎样改进？
- 要钓更大的鱼，应该怎样改进？
- 钓钩不接触鱼，能钓起鱼吗？
- 能一次钓起两条鱼吗？
