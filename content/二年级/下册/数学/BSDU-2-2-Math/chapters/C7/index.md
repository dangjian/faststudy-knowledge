# 数学好玩：有趣的推理

## 兴趣小组的推理

学校有足球、戏曲和书法兴趣小组。淘气、笑笑和奇思根据自己的爱好分别参加了其中一组。他们三人都不在一个组，你能推理出他们分别在哪个兴趣小组吗？

我不是书法小组的。

我喜欢戏曲。

我不喜欢踢足球。

读懂了吗？

要整理信息，分析出他们分别在哪个兴趣小组……

淘气不在书法小组，他可能在足球、戏曲小组……

信息太多了，我都乱了。

### 初步尝试

画一个表来帮忙，把知道的信息记录下来。

| 姓名 | 足球 | 戏曲 | 书法 |
|------|------|------|------|
| 淘气 | | | × |
| 笑笑 | | | |
| 奇思 | | √ | |

淘气不是书法小组的，在表中相应位置上画"×"。

奇思在戏曲小组，画上"√"。笑笑和我一定不在这组，画"×"。

继续完成上表，说一说他们分别在哪组。

## 挑战升级

学校进行飞机模型制作展览，柜子里有 6 个飞机模型：淘气号、奇思号、妙想号、笑笑号、乐乐号和教练号。请你根据下面的信息，找到它们的位置。

- 淘气号和乐乐号都放在柜子的左侧，淘气号在乐乐号的上面。
- 教练号在最上面一排左侧。
- 妙想号不在最上面，也不在最下面。
- 奇思号没有放在教练号的旁边。
