## 电路出故障了

### 聚焦

电流从电池的一端经导线流出，通过小灯泡，回到电池的另一端，形成一个完整的回路，小灯泡就会亮起来。

如果小灯泡不亮，一定是电路出故障了，怎样找到和排除电路的故障呢？

### 探索

电路的故障可能有哪些？如何进行检测？把我们的想法都记录下来。

**电路故障检测记录表（班级记录表）**　日期：（　）月（　）日

| 检测部件 | 可能出现的故障 | 排除故障的方法 |
|----------|----------------|----------------|
| 小灯泡 | 小灯泡坏了 |  |
| 小灯泡 | 小灯泡与灯座接触不良 |  |
| 电池 | 电池没有电了 |  |
|  |  |  |

做一个电路检测器。把简易电路中的开关拆除后，就形成了一个电路检测器。

**提示**　每次检测前，先将两个检测头互相接触一下，看看小灯泡能否亮起来。不能用电路检测器检测家用电路。

每个小组检测一个有故障的电路，找出故障原因并排除。同时，将"电路故障检测记录表"补充完整。
