## 翻滚正方体

如图，正方体的一个面是蓝色的，当正方体在写有数的带子上翻滚时，蓝色面会经过带子上的一些数。

（配图：正方体在写有 11，12，13，14，15，16 等数的带子上翻滚，起点处蓝色面朝上）

正方体从起点开始翻滚，蓝色面经过的第一个数是几？

- 正方体第一次翻滚，落在 1 上……
- 想象一下翻滚的过程，蓝色面第一次应该落在……

正方体从起点翻滚到 15，蓝色面经过的数分别是多少？想一想，填一填。

|  | 第一次 | 第二次 | 第三次 | 第四次 |
|------|--------|--------|--------|--------|
| 经过 |  |  |  |  |

- 正方体翻滚一圈，蓝色面出现一次，中间相隔 3 个面……
- 正方体翻滚到 4，蓝色面再次朝上，所以蓝色面第二次经过的数应该是 6……

如图，正方体的四个面分别涂上红、黄、绿、蓝四种颜色。四人一组，每人选择一种颜色，记录该颜色的面在正方体翻滚时经过的数，说一说你发现了什么。
