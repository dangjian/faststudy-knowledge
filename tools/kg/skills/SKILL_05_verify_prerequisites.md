# SKILL_05 - 验证 prerequisite（Pass2，高风险）

> ⚠️ **存量边不可信，不要把 `prerequisite.yaml` 里已有的边当作已验证的事实。**
> 随机 60 条六标签标注实测：仅 13.3% 站得住，约 78% 实为 part_of / related / 应删（先修方向判据修订（2026-08））。
> 复核时默认假设是「这条边有问题」，而不是「这条边大概率对，找出个别错的」。
> 三类关系的互斥判据以 `graph/ontology.yaml` 的 `relation_semantics` 为准；
> 标注手册见 `仓外治理记录（不入公开仓）先修方向判据修订（2026-08）-prerequisite-direction/labeling_rubric.md`。
> **LLM 不得单独裁决方向**：实测二分类与真值一致率仅 70%，低于 90% 门槛，必须人工过目。

错前置会误导学习路径生成，风险最高，单独把关。

对 `graph/relations/prerequisite.yaml` 每条 `from -> to`：
1. 确认「学 from 前必须先掌握 to」是否成立。不成立则删除该边。
2. 检查是否引入环（DAG）。`tools/kg lint` 的 cycle 规则会兜底，但此处优先修正。

只保留确凿的前置依赖。可删不可错加。

## 跨年级 prerequisite（允许在证据充分时新增）
SKILL_00 阶段五会产出跨年级 prerequisite 候选（同一学科、低年级 → 高年级）。
> 注：`kg:infer` 的「章节链骨架」已于 2026-08-27 停产（章节链骨架停产（2026-08），章节顺序不是可靠的先修信号），
> 候选只能来自逐条语义判断，不再有机器生成的批量候选可用。

本步除复核既有边外，**允许在证据确凿时新增跨年级 prerequisite**：
- 锚点：同一学科，且 to 所在年级明显早于 from（如 七 → 八、八 → 九、七 → 九）。
- 证据：to 是 from 的**基础概念**（如"整式"是"因式分解"的基础、"一次函数"是"二次函数"的基础）。
- 仍遵循"可删不可错加"：证据不足一律不连，宁可漏不可错。

输出：修正后的 `prerequisite.yaml`（含复核后的跨年级边）。
