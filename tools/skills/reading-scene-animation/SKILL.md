# 朗读 3D 场景(reading-scene-animation)

> 本 skill 是内容生产,**不写学习事件**。
> **只给规范,不给模板**:硬约束必须满足(验收脚本和踩过的坑依赖它们),其余画风、布局、镜头语言按篇目意境自由设计,每篇都该长得不一样。
> **诗文铁律:原文、节奏、注释以部编版教材为准,严禁凭记忆默写当原文。**

## 适用场景

不限古诗。核心机制是**"一句朗读 = 一个镜头"**,满足以下三条就适用:

1. **句句有画面**:多数句子含具体的景物/动作/时间变化(名词能建模、动词能动起来)
2. **篇幅短**:切分后约 4–20 段(每段一个镜头;再多就拆成多页)
3. **学习目标含朗读/背诵**:声音和画面同步,帮助记忆与理解意境

| 类型 | 例子 | 适配要点 |
|---|---|---|
| 古诗 | 《使至塞上》《钱塘湖春行》《黄鹤楼》 | 节奏、韵脚、对仗叠层都用上 |
| 词、曲 | 《天净沙·秋思》《渔家傲·秋思》 | 长短句节奏按教材逐句标;一般无对仗 |
| 文言写景段 | 《小石潭记》《记承天寺夜游》《三峡》 | 一段 = 一个短句或一层意思;节奏标句读停顿;注释放实词 |
| 现代写景散文段 | 《春》《济南的冬天》选段 | 只选画面性强的段落,不做全文;节奏/韵脚可不标 |
| 英语短诗/短文 | 课本诗歌、描写性短文 | 横排;`gen-tts.py` 的 `VOICE` 改英文音色(如 `en-US-GuyNeural`)、`RATE` 调到 `-10%` 左右;逐词点亮 |

**不适用**(换别的方式):

- 议论文、说明文里的抽象论证——没有可建模的画面
- 数理推导、运动过程讲题——用讲题动画 skill（已迁往 learner 层 `wiki/skills/manim-teaching-animation`）
- 需要学生作答/交互的练习——本 skill 只做"看+听",不写学习事件
- 以人物对话、表情为主的叙事——简化模型表达不了神态
- 长篇全文——只挑最有画面感的段落

## skill 自带内容(不依赖仓库内其他文件;Three.js 与 edge-tts/playwright 需联网安装)

```
reading-scene-animation/
├── SKILL.md
└── scripts/
    ├── fetch-three.sh                  # 现下 Three.js 0.180 到产出 lib/
    ├── gen-tts.py + requirements.txt   # 逐句 TTS + 逐字时间 timings.json(edge-tts)
    └── shoot.mjs + package.json        # 逐句截图 + 跳读一致性对比(playwright,就地 npm i)
```

下文 `<skill>` 指本 skill 目录;产出根目录 `<out-dir>` 自定(输出目录自定,各篇共用同一份 lib),下文产出路径都相对它。

## 产出物

```
<out-dir>/                      # 输出目录自定,各篇共用一份 lib
├── lib/                       # three.module.min.js + three.core.min.js(两者须同目录)
└── <id>/                      # id = 篇名拼音,如 shizhisaishang
    ├── index.html             # 单文件:数据 + 场景 + 播放器
    ├── 0.mp3 … n.mp3          # 0 = 标题句,1..n = 正文各句
    └── timings.json           # 逐字时间,gen-tts.py 产出
```

- 产出放自定的 `<out-dir>`,**不写进本 skill 目录**
- `lib/` 已存在就复用;没有则 `bash <skill>/scripts/fetch-three.sh <out-dir>/lib`
- 打开:`npx -y serve <out-dir>` → `/<id>/`(`file://` 双击会拦截 ES module、fetch 与音频连播)

## 篇目设定单(动手前先填,写进汇报)

规范是通用的,设定单是这一篇的。先想清楚再写代码,**填的是判断,不是代码**:

| 项 | 填什么 |
|---|---|
| 意境 | 一句话:这篇要让人感到什么(如"苍茫孤寂中的壮阔") |
| 重点意象 | 1–3 个,建模和动画的精力集中在这里(如孤烟、落日);其余景物从简 |
| 色板 | 4 个语义色,写成 `:root` 变量:**底**(大面积背景/面板)、**字**(正文)、**强调**(韵脚、按钮、当前态)、**点缀**(少量辅助,如注释标签)。例:江南春景 = 宣纸 / 墨 / 印章红 / 松绿;边塞 = 夜黑 / 月白 / 落日橙 / 沙黄 |
| 分镜表 | 每句一行:画面 / 动画 / 镜头 / 天色(见 Step 2) |
| 字卡 | 相邻两句时间或空间跳跃大(白天→夜晚、换地点、换季节)时,转场前插一张字卡(如"日暮""萧关") |
| 禁止项 | 这一篇不该出现的东西,例:边塞诗不出现绿树繁花;写雪景不出现暖色太阳;不加原文没有的人物 |

**优先级**(冲突时按序取舍):原文准确 > 朗读与画面同步 > 文字可读(叠层不挡、字够大) > 重点意象表现 > 氛围细节

## 设计规范

### 硬约束(必须满足)

**技术**
- 单文件 `index.html`,`<script type="importmap">` 映射 `"three": "../lib/three.module.min.js"`;**不引任何 CDN**(国内加载不稳),不引其他库
- 音频相对路径 `${i}.mp3`,`i` 与句序对齐(0 = 标题句);`timings.json` 用 `fetch` 加载,失败直接抛错(不静默降级)
- 控制台零报错(`shoot.mjs` 会收集 pageerror / 请求失败 / console.error)

**验收契约**(`shoot.mjs` 依赖)
- `#start`:开始按钮;播完后变为"再听一遍"并可再次点击
- 每句正文都有可点击跳读的元素,带 `data-cue="<句号>"`(1..n),文档顺序即句序
- 全页只有一个 `<audio>`(脚本靠它定点暂停截图)

**播放**
- **只用一个 `<audio>` 换 src**——iOS 首次点击解锁后才能自动连播,多个 audio 会卡住
- 句间停顿约 0.7s 后自动播下一句;支持暂停/继续、上一句/下一句、点句跳读
- 跳句时 `pause()` 会打断上一次 `play()` 的 Promise:**只忽略 `AbortError`**,其他错误照常抛出
- 场景每帧读取 `{ line, progress }`(progress = 当前句音频进度 0..1),**动画由朗读进度驱动**(烟随读升起、日随读落下),不要用与音频无关的定时器

**跳读与顺播状态一致**
- 画面状态(物体显隐与位置、天色、镜头目标)**只由 `(line, progress)` 算出**,不依赖"之前播过哪些句";禁止"某句播过就置一个标志"这类累积状态
- 镜头可以阻尼过渡,但同一 `(line, progress)` 下最终要落到同一位置
- `shoot.mjs` 会倒序跳读每句,和顺播同一时刻的截图逐像素比较

**逐字点亮**
- 当前句大字**逐字点亮**:第 k 个字在 `audio.currentTime >= timings[line][k].s` 时亮起;句子播完(`ended`)时全亮
- 同样只由当前音频时间推导(跳读、暂停后状态正确);字按下标与 `timings.json` 对齐,节奏"/"等非字元素不占下标

**学习信息**(按篇目取舍,数据全部来自教材)
- 当前句大字显示,附课下注释
- 全文列表:当前句高亮,未读句淡化(读到才显现,帮助背诵)
- 节奏划分用"/"标出;韵脚字用强调色
- 对仗联:上句读时显示上联词,**下联词读到下句才揭晓**(先猜后看)

**UI 与适配**
- UI 颜色只用设定单色板的 `:root` 变量(可带 `-rgb` 变体做透明度);**UI 严禁硬编码颜色**。3D 材质色集中写在一个常量对象里(场景材质,不算 UI)
- 桌面 1280×760 与手机 390×844 下,全文列表 / 对仗 / 当前句 / 控制按钮互不重叠
- 竖排(`writing-mode: vertical-rl`)时容器要 `flex-direction: column`,才是每句一列、从右往左

### 自由发挥(鼓励每篇不同)

- **画风**:低多边形、水墨晕染、剪纸、版画、夜景粒子……按意境选。边塞诗的苍茫与西湖的明媚不该是同一种画面
- **布局与版式**:竖排卷轴、横排字幕、题签、印章……叠层样式与动效自定
- **镜头语言**:推拉摇移、转场方式、节奏快慢、字卡样式
- **氛围**:天色、光影、雾、粒子、季节变化
- **数据结构**:怎么组织句子/注释/对仗数据自己定,满足上面契约即可

## 流程

### Step 1 定篇目与原文

1. 确认篇目、教材册次单元(页面上显示,如 `八年级上册 · 第三单元 · 12 唐诗五首`)
2. 原文优先查知识库 `Sentence` 节点;没有就请用户给原文或教材页码
3. 定每句的节奏划分(五言二三、七言二二三,按教材)、韵脚、课下注释、对仗联

### Step 2 填设定单、写分镜表(动手建模前必须先写)

每句一个镜头,画面从文字里取:**名词 → 物体,动词 → 动画,时间词 → 天色**。再定一条贯穿全篇的天色/光影曲线,让画面有时间推移。示意(《使至塞上》,仅说明方法,不要照搬):

| 句 | 画面 / 动画 | 镜头 |
|---|---|---|
| 5 大漠孤烟直 | 烽烟笔直升起(随朗读进度升高) | 对准烟柱 |
| 6 长河落日圆 | 太阳随朗读沉向河面 | 贴河面平视落日 |
| 7 萧关逢候骑 | 骑兵从远处驰来 | 固定机位看它迎面而来 |

### Step 3 实现页面

按「设定单 + 设计规范」写 `<out-dir>/<id>/index.html`。先定画风与分镜,再写代码;硬约束逐条自查。

### Step 4 生成音频与逐字时间

```bash
python3 -m venv /tmp/ttsvenv && /tmp/ttsvenv/bin/pip install -r <skill>/scripts/requirements.txt
/tmp/ttsvenv/bin/python <skill>/scripts/gen-tts.py <out-dir>/<id> '使至塞上。唐，王维。' '单车，欲问边，' '属国，过居延。' ...
```

- 参数顺序与句序一一对应;第 0 句为「标题。朝代，作者。」
- **逗号制造节奏停顿**(`昔人，已乘，黄鹤去，`),句末用逗号/句号控制语气;标点不进 timings
- **多音字用等长同音字替换**(只改送 TTS 的文字,页面显示原字),逐字排查。已用过:候骑 jì→`候寄`、燕然 yān→`烟然`;常见坑:薄暮 bó、没马蹄 mò、骑 jì、乘 chéng、还 huán、斜 xiá(按教材注音)。**必须一字换一字**,否则逐字点亮会错位
- 脚本逐句打印识别出的字,核对每句字数与页面显示一致;抽听几句确认读音

### Step 5 验收(每篇都要过)

1. 起服务:`npx -y serve <out-dir> -l 3103`;`curl` 确认 `/<id>/`、mp3、`timings.json`、`/lib/three.module.min.js` 均 200(serve 会把 `/<id>/index.html` 301 到 `/<id>/`,正常)
2. 截图与对比(首次:`cd <skill>/scripts && npm i && npx playwright install chromium`):
   `node <skill>/scripts/shoot.mjs http://localhost:3103/<id>/ /tmp/poem-shots/<id>`
3. 读产物,逐条回答下面的「验收问题清单」
4. 关掉服务

## 验收问题清单(逐条回答"是/否",否就修)

| # | 问题 | 依据 |
|---|---|---|
| 1 | 控制台零报错? | `errors.txt` 为空 |
| 2 | 每句跳读与顺播一致? | `consistency.txt` 无 ✗;有 ✗ 看 `consistency.jpg`(左顺播右跳读),找累积状态 |
| 3 | 每句主体清楚可见,没被近处模型挡住? | `montage.jpg`;模型尺寸宁小勿大 |
| 4 | 快速移动的主体是固定机位看它,而不是镜头追拍? | `montage.jpg`;阻尼追拍会让物体冲到镜头前变成大黑块 |
| 5 | 太阳/月亮位置合理,落到地平线下后不可见? | `montage.jpg`;远处地形压低,落下后 `visible = false`,否则俯瞰会看到白色椭圆 |
| 6 | 叠层在桌面和手机上互不重叠? | `montage.jpg`、`mobile.jpg` |
| 7 | 画面体现了设定单的意境、重点意象、色板,没有出现禁止项? | `montage.jpg` 对照设定单 |
| 8 | 逐字点亮与读音同步,每句字数与显示一致? | `gen-tts.py` 打印的字;手动听一句 |
| 9 | 多音字都读对? | 手动抽听 |
| 10 | 暂停/继续、上一句/下一句、播完出现"再听一遍"? | 手动过一遍 |
| 11 | 原文、节奏、注释与教材核对过? | 图谱 `Sentence` 或教材页 |

**环境须知**:截图原图不要直接读(多张 1280px PNG 会超 32MB 请求上限),只读 `shoot.mjs` 的 0.5 倍拼图或先 `sips -Z 640`;npx/playwright 用 Node ≥ 20;无头 Chromium 必须带 `--use-gl=angle`,否则 WebGL 建不起来。
