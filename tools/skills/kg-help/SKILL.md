# kg-help — 意图路由入口

## 命名约定

系列名一律连字符 `kg-xxx`，禁用 `kg:xxx` 冒号写法——冒号是插件命名空间（`plugin:skill`）的保留语法，且 Comate 等工具不支持插件机制。

## 触发(入口词独占约定)

「更新图谱」「加知识」「图谱怎么维护」「用哪个 skill」等**模糊**意图词 → 本 skill。
具体动词(摄入这本教材/查某概念/画脑图…)→ 直接走对应 skill,本 skill 不拦。

## 路由表(输入特征 → skill 链)

| 输入特征 | 路由 |
|---|---|
| 有原始教材/PDF/新书要录入 | `kg-ingest`(全管线编排)→ 末尾 `kg:lint` + `kg:build` |
| 已有正文,要抽概念/关系 | `kg-extract` → `kg:lint` + `kg:build` |
| 只想问知识(概念/先修/覆盖) | `kg-query`(先读 `knowledge/graph/index.md` 定位) |
| 单元/中考复习(聚合概念+解题模型) | `kg-query`；解题模型正文读章节 md 的 `## 解题模型` 区块 |
| 图谱体检/巡检(lint+build、孤儿/环/关系计数) | `kg-review`(只读报告,修复走 kg-edit/kg-extract/kg-ingest/kg-curriculum,按 kg-review 报告分派) |
| 画脑图 | `kg-mindmap` |
| 查先修质量/补 part_of | `kg-verify-prereq` |
| 跨年级成网/课标对齐 | `kg-curriculum` |
| 单点小改(改字段/删一条边/修错字) | `kg-edit`(展示计划→确认→写回→lint) |
| 检测/补齐知识缺口（缺书、缺节、内容偏薄） | `kg-delta`（缺口状态机） |
| 内容修复/校准（越章、错挂、页脚、讹误、表格塌缩、整册校准） | `kg-repair`（五层五步统一方法论，既有工具组合执行） |
| 意图不明 | 先问 1-2 个澄清问题:材料形态(PDF/正文/无材料)?目标学科/教材? |

## 执行约定

1. **识别**:意图模糊时问 1-2 个关键问题,不要猜。
2. **路由**:加载目标 skill,按其流程执行;不在本 skill 里复制它们的逻辑。
3. **串联**:多步链路逐步推进,每步完成汇报结果再进下一步。
4. **收尾**:**涉及写入的链路**输出变更摘要 + `kg:lint`/`kg:build` 结果;纯查询/消费链路只汇报结果。

## 非目标

不替代具体 skill 的执行逻辑;不做本体扩展;只路由和串联。
